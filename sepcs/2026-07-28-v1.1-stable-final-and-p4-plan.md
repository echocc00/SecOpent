## 4. §3.5 剩余性能项（2-3 天，独立可并行）

### 4.1 SSE 背压真实化
**现状**：`main.py:97` demo 循环推假状态。
**实现**（`main.py` 重写 `assessment_events`）：
```python
@app.get("/assessments/{assessment_id}/events")
async def assessment_events(assessment_id: str, request: Request) -> StreamingResponse:
    async def _stream():
        queue: asyncio.Queue[dict] = asyncio.Queue(maxsize=64)
        last_hash = None
        while True:
            if await request.is_disconnected():
                break
            jobs = JobService().all_for_assessment(assessment_id)
            sig = _jobs_signature(jobs)
            if sig != last_hash:
                last_hash = sig
                for j in jobs:
                    try:
                        queue.put_nowait(_job_event(j))
                    except asyncio.QueueFull:
                        # 背压：丢慢客户端，记审计
                        break
            while not queue.empty():
                yield f"data: {json.dumps(queue.get_nowait())}\n\n"
            await asyncio.sleep(1)
    return StreamingResponse(_stream(), media_type="text/event-stream")
```
**关键**：`asyncio.Queue(maxsize=64)` 限流 + `is_disconnected` 清理 + signature 去重（仅状态变化才推）。

### 4.2 Plan DAG 虚拟化
**现状**：react-flow 全量渲染，>50 节点卡。
**实现**（`components/shared/DagView.tsx`）：
```typescript
import { useReactFlow, ReactFlow } from "@xyflow/react";
// 虚拟化：仅渲染视口内节点
import { useVirtualization } from "./useDagVirtualization"; // 自建或用 @xyflow/react 的 nodeExtent

function DagView({ steps }) {
  const { fitBounds, setViewport } = useReactFlow();
  useEffect(() => {
    if (steps.length > 30) {
      const bounds = computeBounds(steps);
      fitBounds(bounds, { padding: 0.2 });
    }
  }, [steps]);
  // 大图用 dagre 分层布局（免依赖的话用简易拓扑排序分层）
  return <ReactFlow nodes={layoutedNodes} edges={edges} onlyRenderVisibleElements />;
}
```
**关键**：`onlyRenderVisibleElements`（react-flow 内置虚拟化）+ `fitBounds` + 分层布局。

### 4.3 adapter --parallel N
**现状**：`SubprocessExecutor` 串行。
**实现**（`infrastructure/adapters/subprocess_executor.py` + Orchestrator）：
```python
class SubprocessExecutor:
    def __init__(self, max_workers: int = 1) -> None:
        self._max_workers = max_workers

    def run_many(self, jobs: list[Job]) -> list[ContainerResult]:
        if self._max_workers <= 1:
            return [self.run(j) for j in jobs]
        from concurrent.futures import ThreadPoolExecutor
        with ThreadPoolExecutor(max_workers=self._max_workers) as pool:
            return list(pool.map(self.run, jobs))
```
**Orchestrator 接线**：`execute_ready` 当前 lease 串行；改用 `run_many` 批量 lease+执行。JobService 的 lease 机制已支持并发（有 owner + TTL），补 executor 并发即可。

### 6.2 实现（`scripts/provision/egress.nft` + `infrastructure/network/nft_scope.py`）
```nft
table inet secopent_egress {
    set allowed_targets { type ipv4_addr; flags interval; }
    chain output {
        type filter hook output priority 0; policy drop;
        ct state established,related accept
        udp dport 53 accept
        tcp dport 53 accept
        ip daddr @allowed_targets accept
        log prefix "SECOPTENT_EGRESS_DROP " drop
    }
}
```
```python
class NftScopeEnforcer:
    def apply_scope(self, snapshot: ScopeSnapshot) -> None:
        ips = self._resolve_with_rebinding_check(snapshot)
        for ip in ips:
            subprocess.run(["nft", "add", "element", "inet", "secopent_egress",
                           "allowed_targets", "{", ip, "}"], check=True)
        # 拒元数据 IP
        for blocked in ("169.254.169.254",):
            subprocess.run(["nft", "add", "element", ...], check=True)

    def revoke(self) -> None:
        subprocess.run(["nft", "flush", "set", "inet", "secopent_egress", "allowed_targets"], check=True)
```
**PolicyEngine 接线**：scope 10-step chain 第 6 步后调 `apply_scope`；评测结束 `revoke`。

## 8. P4 V2 规划（3-4 月，v1.1-stable 后）

用户要求"尽可能把后续任务都规划出来"，故细化 P4 三大方向。

### 8.1 远程 Worker（1-1.5 月）
**问题**：当前适配器在本机 Docker 执行，受单机资源/网络限制。
**设计**：
- **Worker 协议**：gRPC（`protos/worker.proto`），`RunJob(Job) -> Result`
- **Worker 注册**：`POST /workers/register`（心跳 + 能力声明：哪些 adapter + Docker 可用）
- **调度**：Orchestrator 的 `StepRunner` 改为 `RemoteStepRunner`（按能力选 worker）+ 本地 fallback
- **隔离**：每 worker 独立 Docker daemon + scope nftables（P2-G 复用）
- **密钥**：worker 间 mTLS；SecretStore 不下发到 worker（签名/验证回主控）

**任务**：proto 定义 / worker 进程 / 注册+心跳 / 调度器 / mTLS / 容错（worker 掉线 -> job 重试）

### 8.2 多租户（1-1.5 月）
**问题**：当前单用户，要支持多团队。
**设计**：
- **租户模型**：`Tenant` 聚合根，Project/Scope/Assessment/Case 加 `tenant_id`
- **RBAC**：`Role`（owner/analyst/viewer）+ `Permission`（assess:create/case:sign/...）
- **隔离**：行级（每查询加 tenant_id 过滤）+ 密钥 per-tenant（SecretStore 分区）
- **SSO**：OIDC（Keycloak/Authentik）+ JWT claims -> tenant_id + role
- **配额**：per-tenant LLM 预算 / 并发 assessment / 存储上限

**任务**：Tenant 聚合 / RBAC 中间件 / 行级隔离 / SSO / 配额 / 迁移现有数据加 tenant_id

### 8.3 ToB 特性（1-1.5 月）
**设计**：
- **合规报告**：等保 2.0 / GDPR 映射（CoverageMatrix 已映射 OWASP/CIS，扩等保）
- **审计导出**：`GET /audit/export?format=csv|pdf`（防篡改签名）
- **SLA 监控**：assessment 完成时延 / oracle 响应时延 -> Grafana
- **私有 Case 库**：租户私有 Case（不进公共 catalog），签名密钥 per-tenant
- **商业 vuln DB**：Snyk/VulnCheck 接入（Update Bundle 扩展 source 类型）

**任务**：合规映射 / 审计导出 / SLA 指标 / 私有 Case / 商业 DB 适配器

### 8.4 集群化（0.5-1 月，V2 后期）
- PostgreSQL（替换 SQLite，Repository Contract 已抽象，零 domain 改动）
- Redis（JobService lease 持久化 + SSE pub/sub 跨实例）
- 多主控 + 无状态（state 外移到 PG/Redis）
